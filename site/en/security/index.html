Security

La Cigale

Locked, even against extensions

  • Telemetry, studies and crash reports are off; the matching programs are removed from the package.
  • Tor Browser's fingerprinting protection (resistFingerprinting); WebGL, WebGPU and WebRTC off.
  • HTTPS only, TLS 1.2 minimum, no 0-RTT, mandatory OCSP and CRLite.
  • Cookies and cache isolated per site; everything is wiped on close, nothing goes to a disk cache.
  • No saved passwords, no JavaScript in PDFs, no DRM.
  • Extensions sideloaded by other programs are refused.

Verifiable releases

  • Firefox ESR comes from Mozilla: SHA-512 checksum and Mozilla's GPG signature checked, Authenticode signature on Windows.
  • Every release publishes its SHA-256 checksums (SHA256SUMS.txt).
  • One-click update compares the downloaded installer to the published checksum; any mismatch cancels it.
  • The APT repository is signed (ed25519 key, fingerprint 8133 6ADC CAD0 2142 F542 BE53 E231 938C AAB4 F2D5).
  • The APT private key is never in the source code: only the automated build uses it.

What La Cigale contacts

  • Quad9 (Switzerland) for encrypted DNS: it sees the domains you visit.
  • The site's certificate authority (OCSP): it sees which certificate is checked.
  • GitHub, once a day, to check for a new version. Can be turned off on the Protection page.
  • Mozilla, only when you translate a page: the language model is downloaded. The text stays on your computer.
  • api.ipify.org, only when you run the leak test.
  • Your shortcuts' websites, to show their logo. Never Google or a third-party service.

Known limits

  • The Windows installer is not signed: SmartScreen shows a warning. Check the SHA-256 checksum before running it.
  • La Cigale's configuration runs with browser privileges (autoconfig sandbox off), because it needs them. Websites cannot change it.
  • La Cigale does not hide your IP address. The Tor window helps, but for strong anonymity Tor Browser remains the reference.

Audit

  • A static code audit was carried out in November 2026: no critical flaw, one high risk (unverified update) fixed since. Read the report (Chinese).
  • Found a flaw? Report it on GitHub.
