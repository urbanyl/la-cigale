Confidentialité

Mise à jour le 23 novembre 2026.

En bref

  • Le projet La Cigale ne collecte aucune donnée personnelle : pas de compte, pas de serveur à lui, pas de télémétrie, pas de mesure d'audience, pas de cookie.
  • Comme rien n'est collecté, il n'y a rien à consulter, corriger ou supprimer chez nous.

Ce site

  • Il est hébergé par GitHub Pages. GitHub enregistre l'adresse IP des visiteurs pour la sécurité du service, selon sa déclaration de confidentialité. L'éditeur n'a pas accès à ces journaux.
  • Aucun cookie, aucun script de suivi. La police d'écriture est servie par le site lui-même, sans appel à Google ni à un autre service.
  • Les téléchargements se font depuis GitHub Releases, dans les mêmes conditions.

Le navigateur

  • Les données de navigation (historique, cookies, cache) restent sur votre ordinateur et sont effacées à la fermeture, sauf réglage contraire de votre part.
  • Quad9 (Suisse) résout les noms de domaine en DNS chiffré : il voit les domaines visités, sans les associer à un compte.
  • GitHub, une fois par jour, pour vérifier s'il existe une nouvelle version (désactivable dans la page Protection).
  • uBlock Origin télécharge ses listes de filtres auprès de leurs auteurs.
  • Mozilla, seulement si vous traduisez une page ou installez une extension depuis son site.
  • api.ipify.org, seulement quand vous testez votre adresse IP.
  • Les sites de vos raccourcis, pour afficher leur logo.
  • Votre fournisseur de proxy ou le réseau Tor, seulement si vous les activez : ils voient alors les sites visités, selon leurs propres conditions.

Vos droits

  • Pour toute question sur vos données : par une issue sur GitHub, ou en privé par le signalement de sécurité.
  • Vous pouvez aussi saisir la CNIL.
