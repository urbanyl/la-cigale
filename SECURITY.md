# Sécurité / Security

## Signaler une faille

Merci de **ne pas** ouvrir d'issue publique pour une faille de sécurité.
Utilisez le signalement privé de GitHub : onglet **Security**, puis **Report a vulnerability**
(<https://github.com/urbanyl/la-cigale/security/advisories/new>).

Indiquez la version de La Cigale, le système, les étapes pour reproduire et l'impact constaté.
Vous recevrez une réponse dès que possible. Le correctif sort dans une nouvelle version,
et le signalement est rendu public une fois corrigé, avec votre accord pour être cité.

Les failles de Firefox lui-même relèvent de Mozilla : <https://www.mozilla.org/security/>.
Celles d'uBlock Origin, de son auteur : <https://github.com/gorhill/uBlock>.

## Versions suivies

Seule la dernière version publiée reçoit des correctifs.
Chaque version est reconstruite à chaque mise à jour de sécurité de Firefox ESR.

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub private reporting:
**Security** tab, then **Report a vulnerability**. Only the latest release is supported.

Plus de détails sur les protections et les limites : <https://urbanyl.github.io/la-cigale/securite/>.
